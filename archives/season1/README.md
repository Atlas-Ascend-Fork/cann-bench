# Season1 题集归档

本目录保存 Season2 切换前的完整 53 题 `tasks/`，包括原始题目文件、性能 metadata 和版本文件。归档内容来自主仓提交 `524885b`，仅移动路径，不改动文件内容。

当前默认题集为仓库根目录的 `tasks/`，共 60 题。本目录不参与默认任务扫描，历史成绩不得与新题集直接比较。

需要复现旧题集时，在仓库根目录通过 `scripts/run_evaluation.sh --task-dir archives/season1/tasks` 指定历史任务路径，并继续提供该脚本要求的候选包参数。准确复现历史分数还需使用历史评测引擎版本和对应硬件环境。
